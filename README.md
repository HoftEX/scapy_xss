# scapy_xss

Домашнее задание № 8: Scapy и XSS на Google Gruyere
Стариков Владимир Валерьевич

Файлы scapy_gruyere.py - скрипт для захвата и анализа HTTP Surname_Name_HW3.pcap - сохранённый трафик gzip_demo.pcap - пример сжатого ответа


Результаты В pcap 6 HTTP-запросов, все методом GET. В запросах видны Host, User-Agent, Accept-Encoding, Connection и Cookie. Логин передаётся в URL вместе с паролем.

Stored XSS: пейлоад отправлен в параметре snippet, сервер ответил 302, а на странице snippets.gtl появился HTML с атрибутом onmouseover без экранирования. Reflected XSS: пейлоад передан в пути URL, сервер вернул его в div.message страницы ошибки без экранирования.

При сравнении обычных и XSS-запросов видно, что меняется тело ответа: страница сниппетов выросла с 2978 до 3560 байт, главная - с 3851 до 4268 байт. В обоих случаях HTML с пейлоадом возвращается как исполняемая разметка, а не как текст.

Проверка gzip: в gzip_demo.pcap ответ сжат (100 байт), после распаковки получается 93 байта JSON. Скрипт показывает это в выводе.
